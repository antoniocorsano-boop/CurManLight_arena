# CML-633I — Teacher Language and Label Policy

## Language Policy

The guided teacher workflow uses teacher-oriented language that focuses on actionable steps and clear outcomes. Technical labels and internal domain terms are avoided in the main interface.

## Language Guidelines

### Primary Formulations

- "Scegli il riferimento curricolare" (Choose curriculum reference)
- "Verifica che sia adatto alla progettazione" (Verify it's suitable for design)
- "Usa nella progettazione" (Use in design)
- "Controlla le scelte inserite" (Check inserted choices)
- "Prepara il documento" (Prepare the document)
- "Lavoro completato" (Work completed)

### Prohibited Terms

Avoid these technical terms in the main interface:
- A02, A03, A04, A07
- Transfer contract
- Archive
- Entity reference
- Structural footprint
- Canonical payload
- Official
- Approved
- Validated
- Certified

### Recommended Language

| Purpose | Recommended Phrase | Alternative (Avoid) |
|---------|-------------------|---------------------|
| Step title | "Scegli il riferimento curricolare" | "Seleziona entità" |
| Validation | "Controlla ciò che stai usando" | "Verifica dati tecnici" |
| Proceed button | "Continua" | "Avanti" (too generic) |
| Warning | "Avviso: {message}" | "Errore: {code}" |
| Status indicator | "Passo corrente" | "Attuale" |

### Contextual Language

- **Institution configuration**: "Istituto non configurato" (Institution not configured)
- **Content qualification**: "Corrente", "In revisione", "Pianificato localmente", "Legacy", "Sperimentale"
- **Status indicators**: "Passo corrente", "Passi completati", "Passi disponibili"
