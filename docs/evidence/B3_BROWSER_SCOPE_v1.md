# B3 browser evidence scope

The automated browser evidence in this tranche is deliberately limited to the **blocked** institutional-decision path on a clean browser profile.

It proves that the user can reach the real revision workspace, promote a local comparison into a structured proposal, move the proposal through the local review states, reach the authenticated institutional-decision boundary, and remain blocked when no Beta identity is authenticated. It also verifies refresh/re-entry and zero calls to the consequential decision RPC while blocked.

It does **not** prove an authorized institutional decision. That evidence requires a deliberately granted active `collegio` membership in the canonical Beta workspace and will be collected in a separate governed tranche.
